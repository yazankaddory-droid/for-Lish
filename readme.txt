VIDEO
  The video plays from Google Drive, so there is no media folder any more.
  In Drive: right-click the video > Share > General access > "Anyone with the link" (Viewer).
  To swap the video, paste the new file's ID into driveId in js/config.js
  (the long code in the share link between /d/ and /view).
  Below the player there is a "Download it" link as a backup.

TEXT
  The letter lives in js/config.js. Edit the words there.
